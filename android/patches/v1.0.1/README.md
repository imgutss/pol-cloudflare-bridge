# Selected v1.0.1 Android changes

This directory contains **selected source snippets**, not a complete source tree or a reproducible build for the published APK.

- `GeminiInsets.java`: Gemini-specific WebView inset handling on Android 11+; the published APK invokes this from the in-app browser's `WebViewClient.onPageStarted`.
- `pol_llm.cpp`: offline text JNI wrapper, based on llama.cpp commit `919794500475862f6768c353255469dc661cb734`; model stays loaded between requests and generated bytes can be polled. Model context is recreated for each request.

The release APK is available in the [v1.0.1 release](https://github.com/imgutss/pol-cloudflare-bridge/releases/tag/v1.0.1). Offline image input and GPU acceleration are not included. Distribution and licensing of bundled components must be assessed separately; this directory does not alter their licenses.
